# Perth Crime Hotspot Analysis

A data science project that analyses crime hotspots across Perth suburbs using
geospatial clustering and interactive visualisations.

**Data source:** WA Police Force Crime Statistics —
[data.wa.gov.au](https://data.wa.gov.au/dataset/crime-statistics-by-suburb)

---

## Project Overview

This project processes publicly available Perth crime statistics to:

- **Cluster** suburbs by crime type and frequency using K-Means (Scikit-learn).
- **Map** crime intensity as interactive geospatial heatmaps (Folium).
- **Visualise** trends and offence breakdowns with interactive charts (Plotly).

## Getting Started

### Prerequisites

- Python 3.10 or later
- `pip` package manager

### 1. Clone the repository

```bash
git clone https://github.com/kevinkdeveloper/Perth-Crime-Hotspot-Analysis.git
cd Perth-Crime-Hotspot-Analysis
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the analysis pipeline

Execute the scripts in order from the repository root:

```bash
# Step 1 – preprocess raw data
python src/scripts/01_preprocess.py

# Step 2 – cluster suburbs by crime profile
python src/scripts/02_clustering.py

# Step 3 – generate maps and charts
python src/scripts/03_visualization.py
```

Outputs are saved to `outputs/maps/` (interactive HTML maps) and
`outputs/figures/` (charts).

### 4. Explore the Jupyter Notebook

```bash
jupyter lab notebooks/Perth_Crime_Analysis.ipynb
```

## Dataset

The sample dataset (`data/raw/perth_crime_statistics.csv`) is modelled on
the WA Police Force crime statistics format. It contains quarterly offence
counts for 26 Perth suburbs across the 2022/23 financial year, categorised by:

- **Offence Division** (e.g. Offences Against the Person, Offences Against Property)
- **Offence Subdivision** (e.g. Assault, Burglary, Stealing, Motor Vehicle Theft)

To use the full official dataset:
1. Download from [data.wa.gov.au](https://data.wa.gov.au/dataset/crime-statistics-by-suburb)
2. Replace `data/raw/perth_crime_statistics.csv` with the downloaded file
3. Re-run the pipeline
